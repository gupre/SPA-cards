# SPA Cards

Одностраничное приложение для просмотра, фильтрации и управления карточками продуктов. Реализовано как тестовое задание — акцент на качестве кода, архитектуре и работе с Redux.

🔗 **[Live Demo](https://gupre.github.io/SPA-cards)**

---

## Функциональность

- Список продуктов с данными из публичного API
- Лайки с визуальной индикацией (иконка подсвечивается)
- Удаление карточки из списка
- Фильтр: все карточки / только избранные
- Детальная страница продукта `/products/:id`
- Форма создания нового продукта с валидацией `/create-product`
- Все данные (полученные и созданные) хранятся в Redux store

## Запуск

```bash
git clone https://github.com/gupre/SPA-cards.git
cd SPA-cards
npm install
npm start
```

Приложение откроется на `http://localhost:3000`

## Архитектурные решения

- Все данные (загруженные из API и созданные пользователем) унифицированно хранятся в одном Redux slice — это позволяет применять фильтрацию ко всему списку без разделения источников данных
- Лайки и удаление реализованы через Redux actions без обращения к API — состояние хранится локально в store
- Форма создания продукта сохраняет данные напрямую в store, новые карточки отображаются в общем списке наравне с загруженными
